# SuperFedora Artwork 🛸

Brand assets, 16-bit pixel avatars, logos, screenshots, and curated 16-bit retro wallpapers for the **[SuperFedora](https://github.com/SuperFedora)** organization.

## 🎨 Official Avatar

The official SuperFedora avatar features the Fedora teardrop infinity badge rendered in 16-bit retro pixel art, crowned diagonally by the metallic 3D block **"SUPER"** title in iconic *Super Metroid* typography.

* **Primary Avatar:** [`branding/avatar.jpg`](branding/avatar.jpg) (1024x1024)
