# SuperFedora Artwork 🛸

Brand media, 16-bit pixel avatars, logos, and curated retro wallpapers for the **[SuperFedora](https://superfedora.github.io/)** workstation.

* **16-Bit Avatar:** [`branding/avatar.jpg`](branding/avatar.jpg) — Fedora infinity badge crowned with metallic 3D Super Metroid lettering.
* **Pixel Wallpapers:** [`wallpapers/`](wallpapers/) — Curated Tokyo Night and SNES palette indexed wallpapers.
* **Wallpaper Bundle:** Run `./scripts/package.sh` to build `dist/superfedora-wallpapers.tar.gz`.

All desktop media, interactive color themes, and component previews are hosted on the web portal:

**Official 16-Bit Portal & Gallery: [superfedora.github.io](https://superfedora.github.io/)**
