# SuperTheme

[![Release](https://img.shields.io/github/v/release/SuperFedora/supertheme?label=SuperTheme)](https://github.com/SuperFedora/supertheme/releases)
[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

Native Rust 16-bit theme, wallpaper, palette, and synthesized WAV SFX engine (`supertheme`) for **[SuperFedora](https://superfedora.github.io/)**.

```bash
supertheme            # Launch interactive 16-bit Theme, Wallpaper & SFX TUI Studio
supertheme next       # Rotate through 16 rainbow palettes (01-crimson .. 16-fuchsia)
supertheme toggle     # Flip between night (dark) and day (light) mode
supertheme corners    # Toggle 90-degree square vs rounded corners
supertheme wallpaper  # Rotate or list 16-bit pixel wallpapers
supertheme sfx toggle # Enable or mute 16-bit PCM WAV sound effects
```

* **Assets:** `palettes/palettes.toml`, `wallpapers/` (`dark/` & `light/`), `cast/` SVG portraits, `sfx/` 16-bit WAV bank, and `branding/`.

**Full documentation & live palette gallery: [superfedora.github.io](https://superfedora.github.io/)**
